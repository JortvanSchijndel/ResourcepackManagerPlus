# ResourcepackManagerPlus


An attempt at creating a service that allowed for easy collaboration on Minecraft resource packs across multiple servers.

Features:
- Upload and visualize custom models
- Permissions (Review models from team members before uploading them)
- Sending the new resource packs to the Minecraft Servers
- Multiple resource packs (eg. prod/dev resource packs)

Partially works but got discontinued because IngeniaMC was discontinued so I didn't have a use-case anymore.
This prototype was fully vibe coded using Claude, ChatGPT & Gemini. Though I did learn a lot of new things!

*IngeniaMC was a Minecraft theme park project that originally started as MiniBuildCraft in 2018. After briefly evolving into a minigame server, the team returned to its main passion: creating an immersive, magical theme park in Minecraft.
